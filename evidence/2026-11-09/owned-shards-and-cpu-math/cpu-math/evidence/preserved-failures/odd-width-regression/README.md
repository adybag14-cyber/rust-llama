The new even-width packed-GLU guard was incorrect: the original ggml_glu_impl deliberately floors an odd row width, and the unchanged prior glu_packed_odd native regression caught the regression on both hosts/profiles. That guard is removed; the original contract is retained. An independent72-case raw-input addon now covers odd widths3/9/65, both swaps, all three dtypes, and finite/exceptional values across vector-prefix boundaries. Native expected bytes remain unchanged. Entire native-comparison modules are gated to verified profiles, so unsupported targets cannot count empty comparisons as passes.
