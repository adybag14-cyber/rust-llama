# Windows native model/server evidence — 9 November 2026

These are fresh checks of the merged Rust workspace on Windows with the pinned
Rust 1.99.1 toolchain. The `.json` capture files record the exact command,
exit status, timeout/truncation state, elapsed time and hashes of the paired
stdout/stderr files. The Rust `cargo xtask capture` command produced those logs.

| Evidence stem | Observed result |
| --- | --- |
| `server-tests` | 18 unit tests and 20 real TCP tests passed. |
| `source-vocabulary` | All 68 frozen original SentencePiece cases passed; 312 token pieces were checked in both special modes, with exact token IDs and byte output. |
| `pretrained-inference` | Six real model prompts; 96 greedy token IDs; 62,976 individual float comparisons; exact generated bytes and usage. |
| `pretrained-http` | 37 actual HTTP requests passed, including original-model completions, streaming, replay, tokenizer round trips, concurrent requests, stops, and cancellation/error recovery. |
| `release-executable.json` | A release `llama-server --model` process loaded the model, returned health 200 and the exact reference completion, then exited on `quit`. A missing-model startup exited 1 without listening. |

The trained model is the externally stored `stories260K.gguf`, 1,185,376 bytes,
SHA-256
`270cba1bd5109f42d03350f60406024560464db173c0e387d91f0426d3bd256d`.
The model was not added to this repository. Its exact hash is checked by the
Rust conformance test. The HTTP verifier uses the same explicitly supplied
model path and compares the independently captured expected outputs. Original
source/DLL provenance and expected data are in `fixtures/inference/`.

For the explicit ignored trained-model test, the environment supplied
`LLAMA_TEST_MODEL=C:\Users\adyba\rust-llama-reference\models\stories260K.gguf`.
This variable selects an external input, not a product default. On another
machine, set it to the same hash-pinned model's local path. The command recorded
in `pretrained-inference.json` deliberately includes `--ignored`; the ordinary
workspace test result does not count this external-input test as executed.

The float tolerance was declared before comparison as
`abs(error) <= 2e-4 + 2e-5 * abs(reference)`. The observed maximum absolute error
was **1.764297485e-5**, and the greatest fraction of any allowed tolerance was
**0.07180018213**. The comparison includes every prompt-token logit row and
every selected greedy-step logit row; the last prompt row is therefore checked
again as the first greedy row. Greedy token IDs and generated UTF-8 bytes must
match exactly.

The runtime tests use actual trained model inference, with a fresh sequence and
sampler for each request. A stop string crossing token boundaries returned
`, there was a ` and accounted for eight sampled completion tokens while
reporting `stopped_word=true` and `stopped_eos=false`.
The model has no chat template: chat and apply-template are expected to fail
explicitly for this input. Separate ordinary tests cover six native template
transcripts from the original formatter fixtures.

This evidence covers the supported scalar CPU Llama/SentencePiece path and the
listed server routes. It does not certify every model architecture, tokenizer
family, backend, sampling option, CLI flag, protocol or application.
Original C/C++ binaries supply independent expected data outside the product;
the Rust server does not load or call them.

Conformance-tool tests, strict Clippy and source/integrity verification are
recorded separately in `../integration/`.

## Additional quantized-model regression

`pretrained-q4-inference` records the explicit release test selected by
`LLAMA_TEST_Q4_MODEL=C:\Users\adyba\rust-llama-reference\models\stories15M-q4_0.gguf`.
The external model is 19,077,344 bytes, SHA-256
`66967fbece6dbe97886593fdbb73589584927e29119ec31f08090732d1861739`.

All **640,000 Q4_0 model logits** passed the unchanged numerical budget;
on this Windows run every f32 bit pattern matched, with maximum absolute error
**0**. All sixteen greedy token IDs, actual generated bytes, finish reason and
token usage matched the original. Bitwise equality is reported but is not a
portable gate. The original F32 KV, one-thread, flash-attention-disabled profile
is recorded with the expected data in
`fixtures/inference/stories15m-q4-provenance.json`.
The compact 2,560,000-byte binary stores twenty unique full vocabulary rows,
including the shared final-prompt/first-greedy row once; model weights remain
external.
