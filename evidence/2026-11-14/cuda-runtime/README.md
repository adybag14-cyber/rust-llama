# CUDA runtime: final validation and diagnostic history

All four final live GPU runs succeeded: Linux GNU and Windows MSVC, each in release and debug. Each passed strict Clippy and all 15 selected Cargo tests, with zero failed or ignored tests. Execution used the NVIDIA GeForce RTX 4090 on Devbox Hermes.

`acceptance.json` contains derived counts and limits. Exact original reports and stdout/stderr logs are under `final-v2/`; final durable-job metadata is under `final-job/`. This package was created only after all four reports and the durable job succeeded.

The five Qwen groups total **9,837,824 F32 comparisons and 578 exact greedy IDs per run**. The three pretrained Qwen models alone account for **9,420,032 F32 comparisons and 40 exact IDs**. Exact F32 counts and maximum errors are measured separately below; a passing comparison is not assumed bit-exact. The three Llama inputs account for **762,880 logit comparisons and 208 exact greedy IDs per run**. Llama F32 counts include its prompt/greedy boundary row as tested; they are not a claim of that many unique output cells.

The kernel suite checked malformed uniforms in eight guarded kernels, foreign stream/input/output ownership, short input rejection and retained context lifetime. Model tests checked exact owned-allocation budgets, one-byte-under-budget rejection, numeric-failure rollback, cancellation, truncation/reset replay, generated bytes and streaming stop handling. Six Qwen3 Q4_K fixture cases were explicitly rejected before device execution.

The 162 analytical cases include both exact regressions for the independent 98-element RMS division boundary. See `../cuda-review/README.md` and `../cuda-review/review.json`.

## Byte preservation and verification boundary

`artifact-manifest.tsv` identifies every package file except itself. `copy-manifest.json` maps every retained raw artifact to its external source and verifies equal source/destination hashes. Raw logs, metadata, reports and comparison JSON were not rewritten or normalized.

The existing root `* -text` attribute preserves these bytes. No scoped attributes were added. Ordinary source diff checks remain strict. The read-only whitespace scan passed for every non-log package file. Exactly 22 captured stdout logs retain their original blank final line. The four original Qwen2 capture logs under `original/qwen2-native/{msvc,gnu}/{f16,q8_0}-capture.log` each retain trailing whitespace on line 48. `acceptance.json` records every affected path and suggested staged Git commands: disable `blank-at-eof` only for captured logs, and disable `blank-at-eol` only for those four original capture logs. No source whitespace rule is relaxed. Staging and staged Git checks belong to parent integration; the packager verified bytes and did not stage files.

This evidence qualifies the measured dense Llama/Qwen2/Qwen3 corpus on this GPU and these two host profiles. It does not close global port gates or certify other architectures, packed types, graph variants, drivers or devices.
