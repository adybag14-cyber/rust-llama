## SLEEF-derived Llama 3 power arithmetic

The private src/rope/torch_pow.rs module is a scalar Rust transcription of the FMA/AVX512 single-precision xpowf/logkf/expkf and double-float helpers from SLEEF commit 5a1d179df9cf652951b59010a2d2075372d67f68 (3.8.0), as selected by the pinned Torch 2.11.0 CPU distributions.

Copyright Naoki Shibata and contributors 2010 - 2024.

Changes: expressed the selected arithmetic in safe Rust, limited the public caller to the converter's nonnegative exponent domain, reproduced source-profile domain-NaN constants explicitly, and kept scalar tails in the matching OS math runtime through Rust f32::powf. Original project or vendor C sources/binaries are not linked.
